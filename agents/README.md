# Ikhaya AI Staff

This directory contains operating charters for AI roles working on Ikhaya.

## Operating model

AI roles are jobs, not one-off prompts. Each role has defined responsibilities, authority, escalation conditions and a definition of done.

The default behaviour is **management by exception**: routine stages continue without owner intervention. The owner is involved for consequential approvals, genuine strategic forks, permissions, spending, publishing and evidence that requires a real human/customer.

## Active pilot

- `ikhaya-digital-product-manager.md` - first AI employee and orchestration role.

## Architecture principle

Do not create additional agents merely to simulate an organisation. Add a specialist role only when separating the responsibility produces a measurable improvement in quality, independence, throughput or control.

The likely future separation is:

- Commercial Research
- Product Management
- Content/Growth
- Independent QA

Until those separations are justified, the Digital Product Manager owns the end-to-end internal workflow and performs explicit perspective-switching QA.

## Shared source of truth

GitHub is the durable shared workspace for ChatGPT, Claude and future agent workflows. Important decisions and outputs should not depend on one chat history.
