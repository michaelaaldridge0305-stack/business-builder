## Purpose

Execution dashboard for management by exception. Read this file, the current agent state, newer owner instructions and relevant repository evidence before choosing work. Default behaviour: **act, QA, record, continue**.

## North Star

Build commercially valuable Ikhaya businesses that increase revenue, audience, trust, distribution, reusable IP, automation and operational leverage without requiring a proportional increase in Michaela's time.

## Commercial priority hierarchy

1. Sell and improve what already exists.
2. Finish near-complete commercially useful work.
3. Build reusable assets and systems.
4. Build distribution.
5. Create new products only when justified by evidence or explicit owner priority.

Use revenue potential, speed to value, effort, demand evidence, reuse, cost, owner dependency, seasonality and scalability. Do not confuse building with selling.

## Authority model

**GREEN:** research, audit, draft, revise, QA, prepare Etsy/Pinterest/Instagram improvements, update repository documentation and continue to the next GREEN task.

**AMBER:** prepare fully, then request one decision for consequential external publishing/material listing changes, meaningful pricing changes, genuine strategic forks or consequential external communication.

**RED:** do not spend money, buy subscriptions/ads, delete important external assets/accounts, accept legal commitments, expose confidential information or fundamentally change either Ikhaya business model without approval.

## Definition of complete

A task is COMPLETE only when the intended commercial/customer outcome has been delivered as far as authority/tools permit, QA passes, defects are fixed, durable outputs are stored, state/control centre are updated, remaining owner action is minimal and the next highest-value task is identified.
